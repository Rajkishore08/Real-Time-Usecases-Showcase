# Real-Time Digital Twin & AR Use Cases Showcase

A showcase repository containing **20 real-time Digital Twin and Augmented Reality use cases** across 10 operational domains.

## 🌟 Overview

- **10 Scientific & Industrial Domains**: Biotechnology, Healthcare, Infrastructure, Agriculture, Energy & Grid, Manufacturing, Disaster & Environment, Mining, Additive Manufacturing, and Logistics.
- **20 Complete Blueprints & Infographics**: Includes end-to-end architecture diagrams, live sensor pipelines, simulation loops, hardware/software stacks, and prototype test plans.
- **Interactive Web Interface**: Grid View, Stage Presentation Mode, Detailed Dossier Modals, Dynamic Search, Domain Filters, and one-click JSON Export.

## 🚀 Live Demo & Deployment

This project is configured for **Vercel** with automatic zero-config builds:

- **Framework**: Vite + React 19
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Configuration**: [`vercel.json`](./vercel.json)

### Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```

## 📦 Export Data

The full structured requirements and blueprints are available at [`/projects_prototype_requirements.json`](./projects_prototype_requirements.json) or by clicking **"Export JSON"** in the web interface.
